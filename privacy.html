Privacy Policy

CIE-PROEVA Backup is an application used for authorized backup operations.

Data access

The application accesses only the Google user data specifically authorized and necessary to perform its backup functionality.

The application does not request unrestricted access to unrelated user data.

Use of data

Authorized data access is used exclusively to create, store, retrieve, update, manage, and delete information associated with authorized backup operations.

Data protection

Backup information is protected before storage and is processed only for the authorized backup functionality described in this policy.

Data sharing

CIE-PROEVA does not sell Google user data and does not use Google user data for advertising purposes.

User data is not used for purposes unrelated to the authorized backup functionality.

Data retention

Backup information is retained only as necessary for the authorized backup function and may be deleted when it is no longer required.

Authorization

Access is granted by the authorized account holder and may be revoked through the account provider's security and authorization settings.

Policy updates

This Privacy Policy may be updated when necessary to reflect changes in the application's functionality, authorization requirements, or data practices.
