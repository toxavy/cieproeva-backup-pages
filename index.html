CIE-PROEVA Backup

CIE-PROEVA Backup is an application used by CIE-PROEVA for authorized backup operations with Google Drive.

The application requests limited access to Google Drive files required for its backup operations. It does not request general access to all files stored in the user's Google Drive account.

Access is used exclusively to create, manage, retrieve, and delete files associated with authorized backup operations.
